# Changelog

## 0.1.2 beta

- Fix competing mouse capture while the search menu is open.
- Restore mouse look promptly after locating an item or closing the menu.
- Follow the selected chest or ground item without repeatedly searching nearby objects.

Beta build, provided as-is.

## 0.1.1 beta

- Restyle the menu with wood, bronze and warm gold details.
- Add Locate local to ping a nearby remembered chest.
- Add View map to focus the selected location and follow nearby moving cargo.
- Remember dropped items on the ground, with their last observed position.

Beta build, provided as-is.

## 0.1.0 beta

- Search remembered containers and carried items.
- Keep personal item history for each character and world.
- Locate remembered storage with temporary map markers.
- Add optional support for Backpacks, CurrencyPocket, EpicLoot and MultiUserChest.

Beta build, provided as-is.
